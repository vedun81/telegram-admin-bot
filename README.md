# UkrMova Pro — Адмін-панель (окремий застосунок)

Окрема сторінка для вчителя/адміністратора: створення тестів, керування гравцями,
відповіді в підтримку, перегляд результатів. Працює з тією самою базою Firebase,
що й сама гра.

## Чим це відрізняється від старої версії

Стара версія (`admin-panel.html` з попереднього репозиторію) пускала в адмінку
за паролем, зашитим прямо в коді сторінки (`vedun81ansuz81`) — його міг побачити
будь-хто, хто відкрив би файл, а сам файл лежав у публічному репозиторії.

Тут вхід — це справжній вхід через Firebase Authentication (той самий нік і
пароль, що й у грі), і саме право заходити в адмінку окремо перевіряється по
базі (`admins/{uid} = true`). Це поле неможливо виставити собі самому ні з гри,
ні з цієї панелі — тільки вручну через Firebase Console.

## Встановлення

1. Переконайтесь, що у файлі `js/firebase-config.js` стоять правильні дані
   вашого проєкту Firebase (за замовчуванням тут уже вписані ваші поточні —
   якщо змінювали проєкт, оновіть).
2. Переконайтесь, що в базі даних вже опубліковані ті самі
   `database.rules.json`, що й у грі (там прописані права саме для адмінів).
3. Видайте собі права адміна (якщо ще не зробили — інструкція нижче).
4. Відкрийте `index.html` у браузері (можна прямо з диска, або залийте на
   будь-який хостинг — GitHub Pages, Netlify тощо).

## Як видати собі права адміна

1. Firebase Console → **Authentication** → **Users** → знайдіть свій акаунт
   (email виду `ваш_нік@ukrmova.app`) → скопіюйте **User UID**.
2. Firebase Console → **Realtime Database** → **Data** → додайте вузол
   `admins` → усередині додайте вузол з назвою **ваш UID** і значенням `true`
   (тип boolean).

## Вхід у панель

На екрані входу введіть той самий нікнейм і пароль, що використовуєте у грі.
Якщо у акаунта немає прав адміна — панель прямо про це скаже.

## Безпека

- Пароль ніде в коді не зберігається.
- Всі дії (додавання/списання грошей, видалення гравця, відповіді в підтримку,
  створення тестів) відбуваються через Firebase SDK і перевіряються
  Security Rules на сервері — підробити запит з боку клієнта не вийде.
- Видалення гравця тут видаляє тільки ігрові дані (`users/{uid}` і запис у
  `nicknames`). Сам обліковий запис у Firebase Authentication (можливість
  увійти) лишається — видалити його можна тільки вручну через
  Firebase Console → Authentication → Users.
